Реальные пакеты

Выберите папку XDTOPackages из выгрузки конфигурации. Для каждого пакета проверяется, что слияние пакета с самим собой даёт семантически тот же пакет (сравниваются разобранные модели с разрешёнными пространствами имён), а для соседних по имени пакетов — что «всё из A» и «всё из B» воспроизводят A и B. Файлы никуда не отправляются.
