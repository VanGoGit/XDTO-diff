# XDTO Diff

Сравнение и объединение пакетов XDTO 1С прямо в браузере.

Попробуй — https://vangogit.github.io/XDTO-diff/

## Как пользоваться

1. Загрузите два файла пакета из выгрузки конфигурации: `XDTOPackages/<Имя>/Ext/Package.bin`.
2. Нажмите **Сравнить**. Типы сопоставляются по имени и пространству имён, а не по автогенерируемому префиксу, и для каждого свойства видно, чем отличаются версии.
3. Отметьте чекбоксами, что взять из A, что из B, или объедините всё сразу.
4. Нажмите **Собрать итоговый файл** и скачайте готовый `Package.bin`.

## Технологии

Один HTML-файл: чистый JavaScript, без сервера, фреймворков и сборки. Файлы никуда не отправляются, всё происходит в браузере.
