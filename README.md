# XDTO Diff

Сравнение и объединение пакетов XDTO 1С прямо в браузере.

Попробуй — https://vangogit.github.io/XDTO-diff/

## Как пользоваться

1. Загрузите два файла пакета из выгрузки конфигурации: `XDTOPackages/<Имя>/Ext/Package.bin`.
2. Нажмите **Сравнить**. Корневые свойства (`property`), `valueType` и `objectType` сопоставляются по имени, свойства без имени — по `ref`. Ссылки на типы (`type`, `base`, `itemType`, `memberTypes`, `ref`, `xsi:type`) сравниваются по пространству имён, а не по автогенерируемому префиксу.
3. Сравниваются все атрибуты (`nillable`, `form`, `default`, `fixed`, `localName`, фасеты `maxLength`, `totalDigits` и т. д.), дочерние элементы (`enumeration`, `pattern`), вложенные описания типов `typeDef` (включая анонимные `ObjectType` со своими свойствами) и порядок свойств. Для каждого отличия видно, какой атрибут или элемент отличается и какие значения в A и B.
4. Отметьте чекбоксами, что взять из A, что из B, или объедините всё сразу. Выбранная версия типа или свойства переносится целиком.
5. Нажмите **Собрать итоговый файл** и скачайте готовый `Package.bin`. Префиксы пространств имён пересобираются для всех ссылок на типы, в том числе внутри `typeDef`.

## Тесты

`tests.html` загружает ядро из `index.html` и проверяет:

- синтетические пары A/B: изменения `nillable`, `lowerBound`, `enumeration`, фасетов, `typeDef`, корневого свойства, `itemType`, `memberTypes`, `xdto:qualified`, порядка свойств — тип помечается изменённым и при выборе стороны переносится её версия; пакеты, отличающиеся только префиксами, совпадают;
- реальные пакеты: выберите папку `XDTOPackages` — для каждого пакета проверяется, что слияние с самим собой даёт семантически тот же пакет, а для соседних пар — что «всё из A» и «всё из B» воспроизводят A и B.

Страницу нужно открывать через http-сервер (например, `python -m http.server` в папке репозитория) или на GitHub Pages.

## Технологии

Один HTML-файл: чистый JavaScript, без сервера, фреймворков и сборки. Файлы никуда не отправляются, всё происходит в браузере.
